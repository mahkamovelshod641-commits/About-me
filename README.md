# Elshod Mahkamov — Shaxsiy Portfolio Sayti

Kod muharriri (VS Code) uslubida yasalgan shaxsiy "O'zim haqimda" sayti. Sayt to'rtta bo'limdan iborat: About, Skills, Projects, Contact — xuddi kod fayllari orasida almashgandek ko'rinishda.

## Texnologiyalar
- HTML5
- CSS3 (custom properties, animatsiyalar, responsiv dizayn)
- Vanilla JavaScript (framework yo'q)

## Xususiyatlar
- VS Code interfeysini eslatuvchi dizayn (sidebar, tablar, qator raqamlari)
- Har bir bo'lim JavaScript kod ko'rinishida yozilgan (about.js, skills.js, projects.js, contact.js)
- Ko'nikmalar progress-bar bilan ko'rsatilgan
- Loyihalar bo'limi va real demo havolalar
- Telegram, Email va GitHub orqali bog'lanish havolalari
- To'liq responsiv (mobil qurilmalarda ham yaxshi ko'rinadi)

## Ishga tushirish
`index.html` faylini VS Code'da oching, "Live Server" kengaytmasi bilan ishga tushiring yoki to'g'ridan-to'g'ri brauzerda oching.

## O'zgartirish
`about.js`, `skills.js`, `projects.js`, `contact.js` bo'limlaridagi matnlarni `index.html` fayli ichida tegishli `<div class="panel">` bloklaridan tahrirlashingiz mumkin. Yangi loyiha qo'shish uchun `projects` bo'limiga yangi `.project-card` blokini nusxalab qo'shing.
